# 🏡 Recanto das Marias

### Site institucional | Festas e Eventos

Projeto de desenvolvimento web criado para apresentar o Recanto das Marias, um espaço destinado à realização de festas, comemorações e eventos em Poços de Caldas – MG.

O objetivo do projeto é oferecer uma apresentação digital do espaço, destacando sua estrutura, ambientes e facilidades de contato para pessoas interessadas em realizar eventos.

---

## ✨ Sobre o projeto

O site foi desenvolvido com foco em apresentar o espaço de maneira visual, organizada e acolhedora, proporcionando aos visitantes uma experiência simples de navegação.

A página reúne informações sobre o Recanto, apresenta os ambientes disponíveis e permite que os interessados solicitem um orçamento diretamente pelo WhatsApp.

## 🚀 Funcionalidades

- Apresentação institucional do Recanto das Marias.
- Seção sobre o espaço e sua localização.
- Apresentação da estrutura e dos ambientes.
- Galeria de imagens.
- Formulário para solicitação de orçamento.
- Integração do formulário com WhatsApp.
- Atalho para contato direto pelo WhatsApp.
- Navegação por seções da página.
